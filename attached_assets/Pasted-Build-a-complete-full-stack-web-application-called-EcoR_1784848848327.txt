Build a complete full-stack web application called "EcoRecicla Bogotá".

This is a university software engineering final project. The application is a Recycling Management System for Residential Complexes in Bogotá, Colombia.

The objective is to help administrators manage recycling activities, recyclable materials, residents, collection events, recycling records, and environmental reports.

Create a modern professional web application similar to an enterprise management system.
