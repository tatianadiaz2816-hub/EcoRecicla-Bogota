# Proyecto EcoRecicla Bogotá
Aplicacion web para la gestión del reciclaje en conjuntos residenciales de Bogotá.

Proyecto de grado desarrollado para optar al título de Ingeniera de Sistemas.
## Descripción
EcoRecicla Bogotá es una aplicación web diseñada para facilitar la administración de programas de reciclaje en conjuntos residenciales de Bogotá. Permite registrar materiales reciclables, gestionar jornadas de recolección, administrar usuarios y generar reportes estadísticos para apoyar la toma de decisiones y promover una cultura de reciclaje.
## Objetivo
Desarrollar un sistema web que optimice la gestión del reciclaje en conjuntos residenciales mediante el registro, seguimiento y análisis de la información relacionada con las actividades de reciclaje.
## Funcionalidades

- Inicio de sesión seguro.
- Dashboard con indicadores y gráficos.
- Gestión de conjuntos residenciales.
- Gestión de usuarios.
- Gestión de materiales reciclables.
- Registro de reciclaje.
- Programación de jornadas de recolección.
- Reportes estadísticos.
- Exportación de información a PDF.
- Exportación de información a Excel.
- Diseño responsive.
- Interfaz completamente en español.

La aplicación sigue una arquitectura cliente-servidor.

- Frontend desarrollado en React.
- Backend desarrollado con Express.
- Persistencia de datos en PostgreSQL.
- Comunicación mediante API REST.
